# File is the investigation identity; discrepancy is an investigative handle

The product/operator term **File** and the Foundation Model term **Case** name the same durable scope of investigative attention; they must not become separate objects or truth stores. Public File identity is domain-neutral (`DD-####`) while Domain remains classification/navigation. The four-digit filing number is deliberately non-semantic and non-sequential: it does not encode creation order, archive size, Domain, priority, truth, or any other investigative judgment. Opening another File does not imply incrementing the prior public number. Internal creation, admission, and revision history remains honest metadata separate from this presentation identifier. A File-scoped discrepancy (`D##`) is a durable handle containing a concise question/description, minimal lifecycle, links to supporting Record material, and update history; it is not a new proposition authority, global ontology, or proof that any explanation is true.
