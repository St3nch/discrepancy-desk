# 3. Research runs are scoped to questions, not stages

Date: 2026-08-03

## Status

Accepted

## Context

A topic is not a question. Handed a topic, a model produces a summary — plausible,
organised, and answering nothing anyone asked. The previous project produced five
such drafts on its only live case and retired all five.

Research also does not proceed in a line. Findings open new questions; the useful
next step is frequently unknowable before the current step returns.

## Decision

A run carries an explicit question and a bounded scope, and produces captured
material, claims, and new open questions. The executor proposes which new questions
are worth pursuing, with rationale; the human approves, rejects, edits scope, or
writes his own. Approved questions become the next run. Nothing dispatches without
the human.

The six-stage editorial sequence — official foundation, public question, deep
context, story intelligence, editorial development, composition — is demoted from a
pipeline to a coverage gauge. It reports what a case has genuinely worked, in any
order. A case can be on run seven and still filling its official foundation because
run four opened a hole in it.

One autonomous deep run was rejected: a bad official spine would be discovered only
after a full case, three angles, and a draft had been built on top of it. It also
puts four differently-shaped jobs behind one prompt and one tool surface, which is
how an agent wanders.

Staged-but-auto-advancing was rejected because a checkpoint that defaults to proceed
is not a checkpoint.

## Consequences

Open questions become a first-class worked object with dispositions — promote to a
run, park, answer from existing material, rule out of scope — or they pile into an
unusable list.

Runs carry lineage: which run introduced which claims, and which question prompted
the run. Cheap at dispatch time, impossible to reconstruct later.

The gate that no angle work begins before the official spine is complete survives,
now evaluated as a condition against coverage rather than a stage marched through.
