# 10 — Coverage gauge and official-foundation gate

**What to build:** A case shows a coverage gauge reporting which of the six research stages
(official foundation, public question, deep context, story intelligence, editorial
development, composition) it has genuinely worked, based on real activity — not a stage a
run merely claims to be. Angle work is hard-blocked until official-foundation coverage
reads complete.

**Blocked by:** 04 — Capture (Vault), 05 — Claim proposal, 08 — Run close: agenda and open
questions

**Status:** ready-for-agent

- [ ] The case view shows a reading for each of the six stages, derived from actual
      captures/claims/open-question activity on the case.
- [ ] The gauge is explicitly not a state machine — stages can be worked out of order and
      revisited.
- [ ] Any attempt to start angle work (ticket 11) on a case whose official-foundation stage
      does not read complete is refused.
- [ ] The governed operation is tested at the agreed seam, including the refusal case for
      the official-foundation gate.
